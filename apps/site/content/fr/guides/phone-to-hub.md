# Connecter ton téléphone

L’app Hemmia se connecte à ton hub avec un code QR. Ton téléphone se connecte alors à ton compte, sans phrase de passe à taper sur le téléphone.

## Pendant la configuration

La dernière étape de la configuration du hub, **Ajoute ton téléphone**, affiche un code QR. Ouvre l’app Hemmia sur ton téléphone, touche **Scanner le code** et pointe l’appareil photo dessus.

## Plus tard, ou un autre appareil

<!-- steps -->
## Ouvre les réglages de ton compte
Sur un appareil déjà connecté, ouvre **Réglages → Compte** et trouve **Connecter un autre appareil**.

## Affiche le code
Saisis ta phrase de passe et touche **Afficher le code de connexion**. Le code fonctionne une fois, pendant 10 minutes.

## Scanne-le
Dans l’app Hemmia sur l’autre téléphone, touche **Scanner le code**. Sur un ordinateur, ou pour utiliser Hemmia dans le navigateur du téléphone, touche plutôt **Copier** à côté du lien et ouvre-le dans le navigateur de cet appareil.
<!-- /steps -->

Si la page dit que l’ordinateur n’a pas encore d’adresse joignable par d’autres appareils, active d’abord Hemmia Connect ou configure Tailscale : voir [Hors de la maison](/fr/guides/remote/).

Les admins peuvent aussi ajouter un appareil pour quelqu’un d’autre : **Réglages → Famille**, puis **Appareils** à côté de la personne et **Ajouter un appareil pour …**. Ce code est valable 24 heures. Pour donner un nouveau compte à quelqu’un, utilise plutôt une invitation : voir [Inviter ta famille](/fr/guides/family/).

## Ce que « connecté » veut dire

Une fois connectée, l’app ouvre directement ton hub. Quand le hub est injoignable, l’app le dit et montre ce qu’il faut vérifier : si l’ordinateur est allumé et éveillé, et s’il a internet. Tes discussions sont sur le hub, elles ne s’affichent donc pas tant qu’il est injoignable.

## Plusieurs hubs

L’app peut garder plusieurs hubs, par exemple le tien et celui de tes parents. **Ajouter un autre hub** dans la liste des hubs en ajoute un ; **Changer de hub** dans les réglages d’un hub ramène à la liste. Si tu utilises aussi l’app seule, **Sur ce téléphone** est la première ligne de cette liste.

## Sans l’app

Hemmia fonctionne aussi dans le navigateur du téléphone. Ouvre le lien copié dans Safari (ou Chrome sur Android), puis ajoute-le à l’écran d’accueil : dans Safari, **Partager → Sur l’écran d’accueil**. Active les notifications là-bas dans **Réglages → Compte → Notifications**.

## Retirer un téléphone

Dans **Réglages → Compte → Appareils**, retire un téléphone que tu n’utilises plus ou que tu as perdu. Il est déconnecté tout de suite et a besoin d’un nouveau code pour revenir.
