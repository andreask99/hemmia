# Download

Hemmia is in beta. The iPhone app is in testing on TestFlight, and the Mac package and Docker images follow with the first public release. Want to try it early? Write to [andreas.apps@icloud.com](mailto:andreas.apps@icloud.com) and we'll add you to the beta.

<!-- download -->

The iPhone app works on its own with your own key, or connect to a hub at home. The Mac package and Docker set up a hub at home; [Choosing AI models](/guides/models/) explains which models it can run.
