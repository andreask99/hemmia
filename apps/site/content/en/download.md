# Download

Hemmia is in beta. Hemmia at home is available as version 0.5.0 for a Mac and with Docker: see [Set up Hemmia on a Mac](/guides/mac/) and [Set up with Docker](/guides/docker/). The iPhone app is in testing on TestFlight: write to [andreas.apps@icloud.com](mailto:andreas.apps@icloud.com) and we'll add you to the beta.

<!-- download -->

The iPhone app works on its own with your own key, or connect to a hub at home. The Mac package and Docker set up a hub at home; [Choosing AI models](/guides/models/) explains which models it can run.
