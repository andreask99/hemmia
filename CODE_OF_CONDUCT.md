# Code of conduct

Hemmia follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, welcome newcomers, and keep criticism
about the work, not the person. Harassment, insults, and sharing other people's private
information are not accepted anywhere in the project's spaces.

described in the Contributor Covenant's enforcement guidelines.
